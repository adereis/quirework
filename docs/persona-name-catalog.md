# Persona name catalogue

These names are fictional labels for SOP profiles and writers-room
seats. Each pun points toward one primary responsibility.

A name is a mnemonic, not a specification. For example, Quinn T. Shun
still needs a prompt that says which claims to challenge and what
evidence counts.

Choose the name that matches the seat's main responsibility. Put nuance
in the profile's description and prompt instead of adding more puns to
the label.

Keep a chosen label stable while a room or recorded run is active. The
stable label lets colleagues address the same seat by name across
rounds.

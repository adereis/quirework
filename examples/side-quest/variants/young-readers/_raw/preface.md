# Preface

I wrote this book with the help of a computer program called Quirework. This book is also about Quirework.

I know how that looks. A book about a tool, made with that same tool, is either showing off what the tool can do or owning up to something. I have not decided which.

Quirework has no opinion about sentences. It keeps a list of everything a book has promised. Then it reads each chapter against the list, and it tells you when a chapter disagrees. It told me several times while I was writing this one. I fixed most of them.

If you find a place where this book disagrees with itself, you have found something the program missed. I would like to hear about it, though not as much as you might think.

I changed every name in this book, and I exaggerated everything that deserved it.

The rest of this book is about a different book, and what I did instead of finishing it.

# The Name

For a month, give or take, it was called check.py;
I alone had to say it; the name told you why.

Then I named it notes-check; it described a bit more,
But the name was no better than what came before.

From a shoebox, a spreadsheet, a script, it had grown;
Then a folder with four files, a name of its own.

It was first to need naming: a repo was due;
Some night changes, by morning, I couldn't undo.

To put changes in version control was my aim;
For a month, more or less, I had meant just the same.

You can name any folder; a repo needs more
Than a name like "the thing for chapter four".

So I kept back an evening and opened a page;
By midnight, a page full; no name at that stage.

They were puns; punctuation gave each one its due,
Which it shouldn't. With *colon*, I'd not thought it through.

They were jokes, not a name I could type and be done;
There'd be something to tell every time I typed one.

And I kept going on: two a.m. came in view;
Around two, I gave up, opened Otto anew.

I'd meant something quite different; typed "quirk" instead;
And then Otto wrote "quirework", the word that I read.

I kept looking at "quirework", the word on the screen;
Not a pun; it seemed something that ought to have been.

Yet, as far as I found, it did not. I had checked;
It beat all on the page, or a name I'd select.

I'd spent all of the evening in choosing, and yet
What I'd meant to ask Otto is what I forget.

Before thinking it over, I made it that night;
For the first commit message, *Name it* I would write.

I have written some better since then. Not a lot;
In the morning, a README was what the thing got.

If a repo lacks README, it looks cast away;
With no version, a tool looks a script, I would say.

It was zero point one, with no promises yet;
And one page was as short as the README would get.

For some weeks, not a change to that same chapter four;
It had never been quite so consistent before.

In that week, it had stopped being script, came to be
Called a tool. No one else had yet used it but me.

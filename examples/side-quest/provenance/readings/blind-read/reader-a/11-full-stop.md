## Keep reading?

8. It's a satisfying, quiet ending, and I'd happily read more by this author. It's done, so the number is about wanting more of this voice.

## What I expect next

Nothing more from this book. I'd like another one from this writer. If anything, I'd guess Red's "Is there a book in here?" gets the answer it has just received.

## What lost me, or what I didn't believe

"This book said 'eleven chapters'. This book has nine." The tool-catches-its-own-book gag is lovely and loops back to the preface, but I'm slightly unsure of the count, since the files I read number eleven, though two are an index title and a preface, so nine real chapters is right. It works, but only if I count the way the narrator does. Also, "Red... had read the README twice by then" is fine, but I never saw Red actually engage with this book as a book, so his question being answered by the new book feels implied rather than shown. And "Nobody noticed, including me" sits oddly next to Hedda, who notices everything.

## More or less?

Less explaining, since "A tool built to avoid a book can still be how a book gets finished" states the point outright when the Hedda ending ("Which one?") already carries it. More of the closing beats like "The pin holes are still there, in pairs", which do the work with no commentary.
